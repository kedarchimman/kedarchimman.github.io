# Kedarnath Chimman — Portfolio

Interactive single-page portfolio built with plain HTML, CSS and JavaScript.

## Run locally

Open `index.html` in a browser. For the best local development experience, use VS Code Live Server.

## GitHub Pages

1. Create a new public repository for the site.
2. Upload `index.html`, `style.css`, `script.js` and the `assets/` folder.
3. In GitHub: **Settings → Pages → Deploy from a branch**.
4. Select `main` and `/root`, then save.
5. Your site will be available at the GitHub Pages URL shown by GitHub.
